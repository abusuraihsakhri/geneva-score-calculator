    Clinical context and privacy

    Use only in an appropriate diagnostic pathway for a patient with suspected PE. A clinical prediction score is not a standalone diagnostic test, treatment instruction, or substitute for clinician assessment. For severe symptoms or instability, seek urgent medical evaluation.

    No data are transmitted to a server or stored by this application. Calculations run in local JavaScript, with no external scripts, analytics, or cookies.
